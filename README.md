# StopPauseMyMusic

This is a Fabric only mod for Minecraft 26.3.
If you have any issue about the mod, you can open an issue on the GitHub repository.

## Build
Clone the repository
```bash
git clone https://github.com/lucachinou/StopPauseMyMusic.git
```

Build the mod
```bash
./gradlew build
```

## Output
The output jar file will be located in `build/libs`.
- `build/libs/stoppausemymusic-1.0-SNAPSHOT.jar`

## Notes
- This mod is only **client-side**
- Current Minecraft target: **26.3**
- Fabric Loader: **0.19.5**
- Fabric API: not required (vanilla mixins only)
- Build tooling: **Fabric Loom 1.17.20** with **Gradle 9.5.0**
- Identity mappings are generated automatically from `minecraft_version`.
